# KING'S GRILLZ Receipt Studio — User Guide

## What it does

Create branded invoices and paid receipts for Signature Smoked Guinea Fowl, offline, on Windows.

## First launch

1. Install or run KingsGrillzReceiptStudio.
2. No login is required.
3. The app works without internet.

## Create a document

1. Open **New document**.
2. Enter customer name and phone.
3. Confirm product, quantity and unit price.
4. Choose Whole or Chopped.
5. Choose Pickup or Delivery. Delivery fee applies only to Delivery.
6. Choose **Invoice (unpaid)** or **Receipt (paid)**.
7. Click **Save PDF**, **Save PNG**, or both.

Invoices are never marked paid automatically.

## History

- Search by name, phone or document number.
- Reprint PDF or PNG at any time.
- Mark an invoice paid only when you have confirmed payment.

## Backup and restore

- **Backup** copies the local database into your application data backups folder.
- **Restore** replaces the local history with a chosen backup file.

## Settings

Set the default product name, unit price and delivery fee. Changes apply to new documents only. Existing documents keep their original prices.

## Data location

`%APPDATA%\KingsGrillzReceiptStudio\`

Do not delete this folder if you want to keep history across reinstalls.
